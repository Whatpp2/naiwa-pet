# 奶蛙桌宠 (Naiwa Pet)

![奶蛙](docs/naiwa.png)

一个安卓桌面宠物应用：奶蛙会待在屏幕上陪你，能点击互动、说话、交配、生老病死，还能接入 AI 聊天。

## 功能

- 🖱️ 悬浮窗宠物，支持多实例（含 0.3 倍小个体）
- 单击互动（抖动/爱心/音效）、点击随机说话（可接 AI）、拖动（默认开启）、长按打开菜单
- 随机事件：跳舞、哭泣（左小右大泪滴）、坐下、拉屎、尿尿、喂食、说话大笑
- 说话系统：原版笑声 + 头顶气泡 + 按字数叫
- 🤖 AI 对话：默认 deepseek-chat，可自填 API Key / URL / 模型，扮演悲情傻子奶蛙，30% 拒绝回答
- 交配产 0.3 倍后代；跨体型交配大个体被雷劈死；单个体孤单自娱
- 衰老系统：0.3 倍 90 秒长大、1 倍 90 秒老死（翻白眼倒下）
- 死亡循环：骷髅头、复活/清理、重新开始按钮
- 独立排泄物实体，可被任意个体吃掉
- 粒子系统：爱心/星星/音符/宝石/血液/烟雾/白色液体/食物碎屑

## 构建

项目使用 Android 官方构建工具链（无第三方运行库）：

```bash
./build.sh
```

需要：JDK 17、Android SDK（build-tools 35.0.0 + platform android-35）。

## 安装

1. 安装 `build/naiwa-pet.apk`；
2. 首次打开会引导授予「悬浮窗」权限；
3. 再次打开即出现奶蛙。
